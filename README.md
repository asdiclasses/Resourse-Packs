# 🎨 Minecraft Resource Pack Collection

> ✨ A collection of some of the best resource-pack features from other creators, combined with custom modifications and ideas to make Minecraft look better, feel better, and provide useful gameplay improvements.

This project is a personal **side project** where I collect, customize, combine, and experiment with different resource-pack features.

The collection includes features from many different creators, along with my own customizations and modifications.

The main goal is simple:

> **Make Minecraft more beautiful, more useful, and more enjoyable — without changing the core Minecraft experience.**

---

# 🌟 Features

This collection contains a large variety of visual improvements, animations, interface changes, and gameplay-related enhancements.

## 🌙 Dark Mode & Custom Panorama

* 🖤 Nice and comfortable **Dark Mode**
* 🖼️ Custom panorama for the Minecraft menu
* 🎮 Improved visual appearance for game interfaces

# ☀️ Fullbright

A **Fullbright** option is included for players who prefer brighter caves and dark areas.

If you don't want Fullbright, you don't need to remove the entire collection.

Simply disable:

```text
fullbright.zip
```

That's it.

---

# 🎃 No Carved Pumpkin Blur

This feature removes the annoying visual blur that normally appears when wearing a carved pumpkin.

You can also disable this feature separately if you prefer the normal Minecraft effect.

---

# ⭐ Twinkling Stars

The night sky has improved stars that can **twinkle**, giving nighttime a little more atmosphere.

Combined with the other visual improvements, it makes the Minecraft night sky feel more alive.

---

# 🟪 Beacon Fog

Adds improved visual effects around beacons, including **Beacon Fog**.

This gives beacons a more noticeable and atmospheric appearance.

---

# 🖼️ UniquePaintingItems

**UniquePaintingItems** makes paintings easier to identify in Creative Mode.

Instead of having to place every painting to find the one you want:

* 🖼️ The painting item shows a preview
* 🎨 You can more easily identify the painting before placing it

### 🎲 Random

The **Random** version behaves like the normal Minecraft painting item.

---

# 🦎 UniqueAxolotlBuckets

**UniqueAxolotlBuckets** makes it easier to identify which axolotl is inside a bucket.

Instead of guessing which axolotl you are carrying:

> 🪣 The bucket shows the axolotl variant inside it.

This is especially useful when collecting multiple axolotls.

---

# 🟢 Ping Color Indicator

The collection includes a **Ping Color Indicator** for Minecraft servers.

This gives you a quick visual way to understand your connection quality when looking at servers.

# 🚧 Experimental — Animated Minecraft Logo

One of the ideas I'm currently experimenting with is an **animated Minecraft logo/title screen**.

I got the idea from discovering that the **Minecraft logo/title can be changed using a resource pack**.

This has already been demonstrated by projects such as **Pinku's Pink GUI Pack Addon – Full Pink Title**, which shows that the Minecraft title can be replaced through resource-pack techniques.

That made me think:

> **If the Minecraft logo can be changed with a resource pack, could it also be animated using a resource pack?**

As far as I know, **no one has made the Minecraft logo animated using only a resource pack yet**.

So I want to experiment with it and see if it is actually possible.

### 🎬 Current Idea

The idea is to find a way to create an animation for the Minecraft logo while keeping the entire effect inside the resource pack.

The exact technique hasn't been figured out yet.

🛠️ **Status: Experimental / Research**

This is one of the more interesting experiments in this collection, and if I find a way to make it work, it could become a unique feature of the pack.
